# Polityka Prywatności
1. Informacje ogólne.
Niniejsza Polityka Prywatności opisuje zasady działania aplikacji.
Aplikacja nie zbiera, nie przechowuje i nie przetwarza żadnych danych osobowych użytkowników.

2. Zakres przetwarzania danych.
Aplikacja:
- nie gromadzi danych osobowych,
- nie tworzy profili użytkowników,
- nie wykorzystuje plików cookies,
- nie przekazuje żadnych danych do podmiotów trzecich,
- nie prowadzi analityki ani statystyk.

3. Firebase Cloud Messaging (FCM).
Aplikacja korzysta z usługi Firebase Cloud Messaging wyłącznie w celu dostarczania powiadomień push.
W ramach FCM:
- aplikacja nie identyfikuje użytkownika,
- aplikacja nie przypisuje powiadomień do konkretnej osoby,
- urządzenie otrzymuje anonimowy token FCM, służący jedynie do dostarczenia powiadomień,
- token nie pozwala na identyfikację użytkownika i nie jest wykorzystywany do żadnych innych celów.
Aplikacja nie wysyła tokena do żadnych serwerów poza Firebase i nie łączy go z żadnymi danymi osobowymi.

4. Uprawnienia systemowe.
Aplikacja może korzystać z uprawnień systemowych wyłącznie w zakresie niezbędnym do odbierania powiadomień.
Żadne dane uzyskane poprzez te uprawnienia nie są zapisywane ani przesyłane.

5. Usługi zewnętrzne.
Aplikacja nie korzysta z:

- usług analitycznych,
- reklam,
- narzędzi śledzących,
- logowania zewnętrznego.
Jedyną usługą zewnętrzną jest Firebase Cloud Messaging.

6. Bezpieczeństwo.
Aplikacja nie przechowuje żadnych danych użytkowników, dlatego nie wymaga stosowania dodatkowych zabezpieczeń.

7. Zmiany w Polityce Prywatności.
W przypadku aktualizacji aplikacji lub zmian w działaniu powiadomień, Polityka Prywatności może zostać zaktualizowana.
Nowa wersja będzie dostępna w tym samym miejscu.
